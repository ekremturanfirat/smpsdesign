# Mergen SMPS Board

An SMPS board (v0.0.1) designed in Altium during my learning phase at Mergen Elektronik. It is an early prototype design and is not recommended for production.

## Files

- `v0.0.1/Board/SchematicandPCB/` – Altium project, schematic sheets, PCB and a PDF of the schematic
- `v0.0.1/Board/Technical/` – layer drawings and board images
- `v0.0.1/Board/BOM/` – bill of materials
- `v0.0.1/Board/MergenSMPSBoardBooklet.pdf` – board booklet
